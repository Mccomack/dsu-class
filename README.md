# dsu-class

Hands-on Python practice files for DSU class activities, focused on controlling and reading hardware modules (LED, display, motor, speaker, IMU, ToF, dials, and environmental sensors).

## Overview

This repository contains small, single-purpose scripts under `python/` that appear to be lesson exercises and mini missions.  
Most files are numbered by class step (`1_*`, `2_*`, `3_*`, `4_*`) and demonstrate one concept at a time.

## Repository Structure

```text
python/
  1_display1.py       # basic display output exercise
  1_led1.py           # basic LED control
  1_led_mission1.py   # LED mission/challenge script
  1_motor.py          # motor control basics
  1_speaker.py        # speaker/buzzer sound output
  2_IMU.py            # IMU sensor reading
  2_Tof.py            # ToF distance sensing
  2_dials.py          # dial/knob input handling
  2_envs.py           # environment sensor values
  3_t1.py ~ 3_t4.py   # task/assignment scripts for unit 3
  4_t1.py             # task/assignment script for unit 4
  guehean.py          # custom class exercise script
  hanbal.py           # custom class exercise script
  hello.py            # general combined test/hello script
```

## Requirements

- Python 3.8+ (recommended)
- Hardware-specific Python libraries used by your class board/environment
- A compatible embedded board or lab setup (as used in DSU class)

> Note: This repository currently has no dependency manifest (`requirements.txt` or `pyproject.toml`), so package installation depends on your class environment.

## Getting Started

Clone and run any script directly:

```bash
git clone https://github.com/KusBeoms/dsu-class.git
cd dsu-class/python
python hello.py
```

Run a specific lesson file:

```bash
python 1_led1.py
python 2_IMU.py
python 3_t4.py
```

## Learning Flow (suggested)

1. Start with `1_*` files for output/control basics (LED, display, motor, speaker).
2. Continue with `2_*` files for sensor input (IMU, ToF, dials, env sensors).
3. Try `3_*` and `4_*` files as integrated tasks/challenges.
4. Use `hello.py`, `guehean.py`, and `hanbal.py` for extra experiments.

## Notes

- File naming is lesson-oriented rather than package-oriented.
- Scripts are likely intended to run individually, not as a single application.
- `python/__pycache__/` is generated bytecode cache and can be ignored.
